## 🚀 Overview

This portfolio is designed to showcase projects, skills, and professional experience in a clean, interactive format. It features smooth animations, responsive design, and easy-to-edit configuration files.

### ✨ Features
- 📱 **Fully Responsive:** Optimized for both mobile and desktop viewing.
- 🎨 **Modern UI/UX:** Built with Tailwind CSS and enhanced with Framer Motion animations.
- ⚙️ **Easily Customizable:** Project, skill, and experience data are centralized in simple data files.
- ⚡ **Blazing Fast:** Powered by Vite for near-instant development server starts and optimized production builds.

## 🛠️ Getting Started

To get a local copy up and running, follow these simple steps:

### 1. Clone the repository
```bash
git clone https://github.com/ayush-244/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## ⚙️ Customization

You can easily personalize this portfolio by modifying the data files located in the `src/data` or `src/components` directories:

* **Projects:** Update with your own projects.
* **Skills:** Add your technical skills.
* **Experience:** Outline your professional work history.
